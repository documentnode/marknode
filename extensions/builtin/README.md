# Built-in extensions

The extensions that ship inside MarkNode live here; they are added in a later release, so this
folder holds only this file for now. Each built-in extension is a package folder named after its
`documentnode.*` id (for example `documentnode.toc/`), written against the public extension API
only, so it doubles as a reference example. See [`../README.md`](../README.md) for the package
format.
