# MarkNode

A Markdown editor with a mind map, an outline and a live preview of the same document.

## What this repository is

This is MarkNode's public home. It holds documentation, release metadata, and the
**[extension authoring kit](extensions/)**: the TypeScript types, a guide, and working examples for
writing your own MarkNode extensions. The MarkNode application itself is closed source and is not
in this repository.

- **[`extensions/`](extensions/)** — everything you need to write, build and install an extension.
  Start with [`extensions/README.md`](extensions/README.md). This directory is MIT-licensed.
